 ⚔️ Console RPG

Консольная пошаговая ролевая игра на C# с системой прокачки, механикой пошагового боя и управлением сохранениями в формате JSON.

Данные персонажа записываются в локальный файл `save.json`, поэтому прогресс сохраняется при перезапуске игры.

 🛠 Технологии

- **C# / .NET**
- **System.Text.Json** (сериализация и десериализация данных персонажа)
- **System.IO** (работа с файловой системой)

⚙️ Функционал

- `1. В бой` — пошаговое сражение со случайным противником (Гоблин или Орк), получение опыта и шанс выпадения зелья.
- `2. Выпить зелье` — восстановление здоровья персонажа с ограничением по количеству банок.
- `3. Сохранить` — запись текущего состояния персонажа (уровень, здоровье, зелья) в файл `save.json`.
- `4. Сбросить сохранение` — полное удаление файла сохранения и сброс текущего профиля с возможностью создать нового героя или выйти.
- `5. Выход` — завершение сессии игры.
